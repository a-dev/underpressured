## Description

1477 of 4000 characters

```text
Underpressuredは、画像を圧縮・変換・リサイズする無料のオープンソースMacアプリです。フォルダ丸ごとでも画像1枚でもドロップして設定を選べば、まとめて処理します。設定はプリセットとして保存して次回も使えるほか、結果の保存先も選べます。処理が終わったら、前後のファイルサイズを比較できます。

処理はすべてMac上で行われます。アップロードは一切なく、アカウント作成も不要で、解析データも収集しません。

設定を覚えるプリセット
• JPEGまたはPNGで保存、または元の形式のまま
• 画質は0〜100で自由に設定、またはロスレス
• 幅、高さ、長辺のいずれかでサイズを制限。縦横比は保たれ、拡大されることはありません
• EXIF、GPS、IPTC、XMPなどのメタデータを保持または削除
• 4つのプリセットを内蔵：「バランス」（JPEGに変換）、「Web」、「小」、「スクリーンショット」（PNGに変換）。編集・複製・並べ替えができ、最大20個まで保存可能
• Command-1〜Command-9でプリセットを切り替え。うっかり変更しても取り消せます

小さくなったファイルの保存先
• オリジナルを置き換え。念のため、上書きせずにオリジナルをゴミ箱に移動することもできます
• または選んだフォルダにコピーを書き出し。ドロップしたフォルダはサブフォルダ構成を維持
• 既存のファイルは決して上書きしません。代わりにphoto-2.jpgのように連番を付けます
• 保存したファイルは元の日付、Finderタグ、アクセス権を引き継ぎます
• 結果はまず一時ファイルに書き込まれ、保存前に元ファイルが変更されていないことを確認します

対応フォーマット
開ける形式：JPEG、PNG、HEIC、WebP、TIFF、AVIF、JPEG XL。保存できる形式：JPEG、PNG。GIF、RAW、アニメーション画像、複数ページのTIFFには対応していません。

内部のしくみ
• jpegliでプログレッシブJPEGを書き出し。ロスレスモードではピクセルデータを再エンコードせずにJPEGを書き直します
• パレット削減で非可逆PNGを小さくしつつ、画質の下限を守ります
• oxipngで、ピクセルを一切変えずに可逆PNGを圧縮
• リサイズにはリニア光でのLanczosフィルタを使用
• カラープロファイルはそのまま引き継ぎ。再エンコード時にCMYK画像をsRGBに変換

やめどきを知っている
• 圧縮でファイルが大きくなる場合はオリジナルを残し、「すでに最適です」と表示
• 同じ設定で最適化済みの画像はスキップ
• 不可視ファイル、パッケージ、画像以外のファイルには手を付けません

Macのために
• ウインドウやDockアイコンにファイルやフォルダをドロップ、「ファイル」>「開く」、Finderの「このアプリケーションで開く」にも対応
• クイックルックでプレビュー、開く、Finderに表示
• 結果を絞り込み：最適化済み、スキップ済み、失敗、キャンセル済み
• 気が変わったらキュー全体をキャンセル。書きかけのファイルは片付けられます
• キューの処理中はMacがスリープせず、バックグラウンドで処理が終わると通知でお知らせ
• 英語、スペイン語、ポルトガル語（ブラジル）、ドイツ語、フランス語、アラビア語、日本語、簡体字中国語に対応

UnderpressuredはMITライセンスの無料オープンソースアプリです。
```
