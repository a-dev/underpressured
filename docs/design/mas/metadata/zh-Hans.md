## Description

1215 of 4000 characters

```text
Underpressured 是一款免费开源的 Mac App，可压缩、转换图像并调整其大小。拖入整个文件夹或单张图像，选好设置，它就会一次处理完毕。你可以将设置存储为预设以便下次使用，还可以选择结果的保存位置。处理完成后，可以对比前后的文件大小。

所有处理都在你的 Mac 上完成。不上传任何内容，无需创建账户，App 也不收集任何分析数据。

记住你设置的预设
• 存储为 JPEG 或 PNG，或保持原始格式
• 质量可在 0 到 100 之间任意设置，或选择无损
• 限制宽度、高度或长边。保持宽高比，图像绝不会被放大
• 保留或移除 EXIF、GPS、IPTC 和 XMP 等元数据
• 内置四个预设：“均衡”（转换为 JPEG）、“网页”、“小”和“屏幕截图”（转换为 PNG）。可编辑、复制和重新排序，最多保留 20 个
• 用 Command-1 到 Command-9 切换预设。不小心改错了？撤销即可

缩小后的文件去向
• 替换原始文件。如需留条后路，Underpressured 可以将原始文件移到废纸篓，而不是直接覆盖
• 也可以将副本导出到你选择的文件夹。拖入的文件夹会保留子文件夹结构
• Underpressured 绝不覆盖已有文件，而是添加后缀，例如 photo-2.jpg
• 保存的文件保留原始文件的日期、访达标签和权限
• 每个结果先写入临时文件，保存前 Underpressured 会确认原始文件未被更改

支持的格式
可打开 JPEG、PNG、HEIC、WebP、TIFF、AVIF 和 JPEG XL。可存储为 JPEG 和 PNG。不支持 GIF、RAW、动画图像和多页 TIFF。

幕后技术
• jpegli 输出渐进式 JPEG。在无损模式下，JPEG 会在不重新编码像素数据的情况下重写
• 调色板缩减让有损 PNG 更小，同时不低于质量下限
• oxipng 无损压缩 PNG，不改变任何像素
• 调整大小使用线性光下的 Lanczos 滤镜
• 保留颜色描述文件。重新编码时，CMYK 图像会转换为 sRGB

适可而止
• 如果压缩会让文件变大，则保留原始文件，并将图像标记为“已是最佳状态”
• 跳过已用相同设置优化过的图像
• 不处理隐藏文件、包以及任何非图像文件

为 Mac 而生
• 将文件或文件夹拖到窗口或程序坞图标上，使用“文件”>“打开”，或在访达中使用“打开方式”
• 用快速查看预览结果、打开结果或在访达中显示
• 按结果筛选：已优化、已跳过、失败或已取消
• 改主意了？可以取消整个队列，Underpressured 会清理未写完的文件
• 队列运行时 Mac 保持唤醒，批处理在后台完成时会通知你
• 支持英语、西班牙语、巴西葡萄牙语、德语、法语、阿拉伯语、日语和简体中文

Underpressured 免费开源，采用 MIT 许可证。
```
